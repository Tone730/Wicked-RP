📷 About Custom Images in Discord

Discord Rich Presence requires images to be uploaded to your Discord application in the Developer Portal. Use the Open Discord Developer Portal button above, go to Rich Presence → Art Assets, and upload your images there. Then copy the Name you give each image into the Image Key field in Wicked RP.

Videos cannot be used in Discord Rich Presence (Discord only supports images). However, you can manage and preview videos here for your own reference.

Setup Guide

  1. 1. Create a Discord Application at https://discord.com/developers/applications
  2. 2. Copy the Application ID and paste it into Wicked RP
  3. 3. Click Connect (make sure Discord desktop is running)
  4. 4. Configure your presence and click Apply Presence

Custom Images

  • Images require uploading to Discord Developer Portal → Rich Presence → Art Assets
  • Copy the asset Name into the Image Key field in Wicked RP
