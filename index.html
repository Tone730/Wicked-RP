🎬 Video in Discord Rich Presence

Discord Rich Presence does not support video — only static images or animated GIFs can be used as presence images.

Workaround: Use an animated GIF as your Large Image Key for a moving effect, or manage your video files in the Media Manager for reference.

🎬 How to Use Animated GIFs (3 steps)

1. Upload your GIF here in the Media Manager, then click the copy button on it — that's your Image Key.
2. Click Upload GIF/Images to Discord above and upload the same GIF there. Name it exactly the same as your Image Key.
3. Paste the Image Key into the Large Image Key field and click Apply Presence — your GIF will animate on Discord!

⚠️ Discord supports animated GIFs but not videos (Discord limitation, not ours). Convert MP4 → GIF to use video clips.

Automations

Your presence updates itself — no keys, no APIs, all local.

Mode: Manual

🎮 Game Auto-Detection

Watches running processes and auto-applies a presence when you start a game. Like Discord's game activity — fully local.

💤 Idle / AFK Presence

After you go AFK, your presence switches to an "Away" activity. Restores automatically when you're back.

🎵 Now-Playing (Spotify, YouTube, any app)

Reads whatever is playing on your PC (Spotify, browsers, players) via Windows — no API keys, no logins.

Example: "🎵 {title}" → "🎵 Blinding Lights". Artist goes on the second line automatically unless you include {artist}.

Setup Guide

  1. 1. Create a Discord Application at https://discord.com/developers/applications
  2. 2. Copy the Application ID and paste it into Wicked RP
  3. 3. Click Connect (make sure Discord desktop is running)
  4. 4. Configure your presence and click Apply Presence

Custom Images

  • Images require uploading to Discord Developer Portal → Rich Presence → Art Assets
  • Copy the asset Name into the Image Key field in Wicked RP
